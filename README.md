# Nour AI — مساعد ذكاء اصطناعي بديل لـ Gemini

## الفتح والتشغيل
1. فك الضغط وافتح فولدر `NourAI` من Android Studio (Hedgehog أو أحدث).
2. استنى الـ Gradle Sync وبعدين Run على موبايلك (Android 8+).

## إزاي يبقى المساعد الافتراضي بدل Gemini
- من التطبيق اضغط "اجعلني المساعد الافتراضي"، أو:
- الإعدادات ← التطبيقات ← التطبيقات الافتراضية ← **تطبيق المساعد الرقمي** ← اختار **Nour AI**.
- (في سامسونج: الإعدادات ← التطبيقات ← اختيار التطبيقات الافتراضية ← تطبيق المساعد الرقمي).
- بعدها الضغطة المطولة على Home / زر الباور (حسب الموبايل) هتفتح Nour بدل Gemini وتبدأ تسمعك على طول.

> ملحوظة: أندرويد مش بيسمح لأي تطبيق ياخد الصلاحية دي لوحده — لازم المستخدم يختاره بنفسه من الإعدادات، وده اللي الزرار بيوديك له.

## إعداد الذكاء الاصطناعي
من أيقونة الإعدادات جوه التطبيق حط:
- **Base URL**: أي API متوافق مع OpenAI، مثلاً:
  - OpenAI: `https://api.openai.com/v1` — model: `gpt-4o-mini`
  - Groq (مجاني): `https://api.groq.com/openai/v1` — model: `llama-3.1-8b-instant`
  - OpenRouter: `https://openrouter.ai/api/v1`
  - Gemini نفسه: `https://generativelanguage.googleapis.com/v1beta/openai` — model: `gemini-2.0-flash`
- **API Key** بتاعك.

## هيكل المشروع
- `assist/NourVoiceInteractionService` + `NourSessionService` + `NourRecognitionService`: الخدمات اللي بتسجل التطبيق كمساعد رقمي.
- `MainActivity`: شاشة الشات + إدخال صوتي + بيستقبل `ACTION_ASSIST`.
- `AiClient`: الاتصال بالـ API.
- `SettingsActivity` / `Prefs`: حفظ الإعدادات.

## البناء من GitHub Actions (من غير Android Studio)
1. اعمل Repository جديد على GitHub وارفع كل محتويات فولدر `NourAI` (لازم فولدر `.github` يترفع معاهم).
2. أول ما ترفع، هيشتغل الـ Workflow تلقائي (أو من تبويب **Actions** ← **Build APK** ← **Run workflow**).
3. لما يخلص (حوالي 3–6 دقايق) ادخل على الـ run وانزل لتحت عند **Artifacts** ونزّل `NourAI-debug-apk`.
4. فك الـ zip وثبّت `app-debug.apk` على موبايلك (فعّل "التثبيت من مصادر غير معروفة").

## الاختبارات
- `app/src/test/.../AiClientTest.kt`: 9 اختبارات للاتصال بالـ API على سيرفر وهمي (نجاح، 401، 429، 5xx، رد بايظ، سيرفر واقف، من غير مفتاح...).
- `app/src/test/.../AppFlowTest.kt`: 9 اختبارات بـ Robolectric للتطبيق كله (الشات، منع الإرسال المزدوج، زر المساعد بيفتح المايك، الإعدادات، تدوير الشاشة، تسجيل خدمات المساعد).
- التشغيل محلياً: `./gradlew testDebugUnitTest` — وبيشتغلوا تلقائي في GitHub Actions قبل البناء.

## النسخة 2 — النافذة الزجاجية (زي Gemini)
- الدوسة الطويلة على Home/Power بتفتح نافذة زجاجية صغيرة فوق أي تطبيق (من غير ما تقفل اللي إنت فيه).
- المايك **مش** بيشتغل لوحده — بس لما تدوس عليه، والاستماع جوه النافذة نفسها (مفيش شاشة جوجل).
- النافذة بتطول لما تسأل، والرد بيظهر كلمة كلمة (Streaming).
- اسحب لتحت = قفل، اسحب لفوق أو زرار ↗ = افتح التطبيق الكامل (نفس المحادثة).
- شكل الزجاج مرسوم بالكود من غير Blur، فبيشتغل على كل الأجهزة (أندرويد 8 وأحدث).
- أول مرة تدوس المايك هيطلب إذن الميكروفون.

## النسخة 3 — نداء "يا نور" + أدوات + علامة Nour

### الصوت (محرك جوجل، من غير شاشة التسجيل بتاعته)
- الاستماع جوه نافذة Nour الزجاجية بـ `SpeechRecognizer` (مفيش Activity ولا نافذة جوجل).
- عربي + إنجليزي في نفس الجملة: لغة أساسية + `EXTRA_ADDITIONAL_LANGUAGES`، وبنطلب 5 نتايج ونختار اللي فيها الاتنين (`MixedText.pickBest`).
- النص بيروح للموديل ومعاه تعليمة يكتب الكلمات الإنجليزية بحروفها الإنجليزية الصح.

### نداء "يا نور" (On-Device 100%)
- Vosk + grammar محدود بالنداء بس: "يا نور" / "Hey Nour" / "Hi Nour". الصوت مبيطلعش من الجهاز.
- الموديلات بتتنزل مرة واحدة من الإعدادات (عربي ~158MB + إنجليزي ~40MB)، مش جوه الـ APK.
- خدمة Foreground بإشعار صامت (`IMPORTANCE_MIN` + `setSilent(true)` = بدون أيقونة في الشريط).
- بتسمع والشاشة مفتوحة بس، وبتقف لوحدها في: مكالمة / تسجيل صوت من تطبيق تاني / كاميرا / النافذة الزجاجية ظاهرة، وترجع لوحدها.
- بعد الريستارت (قيد أندرويد 14) افتح التطبيق مرة واحدة وهي بترجع.
- بعد النداء: النافذة الزجاجية بتفتح والمايك بيشتغل (لازم Nour يكون المساعد الافتراضي، وإلا بيحاول يفتح التطبيق نفسه).

### Nour ينفذ المهام (Tools)
- أداة `open_app`: الموديل هو اللي يقرر. من الإعدادات تختار لحد 10 تطبيقات مسموحة.
- لو التطبيق مش متثبت بيفتح صفحته في Google Play.
- شغال مع أي API متوافق مع OpenAI (OpenAI / Groq / Gemini / OpenRouter) بـ Function Calling، ولو الموديل رفض الأدوات بنرجع تلقائياً لـ JSON parsing.
- فتح التطبيق بيتأجل ثانية بعد ما الرد يخلص عشان تلحق تقرا الكابشن.

### علامة Nour
- `ui/NourOrbView`: قطرة نور سائلة مرسومة بالكود، بتتنفس / بتتموج مع الصوت / بتلف وقت التفكير. وهي كمان أيقونة التطبيق.

> ملحوظة البناء: الـ Workflow بيبني الـ APK الأول وبعدين بيشغّل الاختبارات (لو فشلت مبتمنعش الـ APK، وتقرير الاختبارات بيتحمّل).

### تحديثات النسخة 4
- **اللغة:** العربي دايماً اللغة الأساسية للصوت (حتى لو الموبايل إنجليزي) + إنجليزي + لغة الجهاز. زرار «لغة الصوت» في الإعدادات (تلقائي / عربي / إنجليزي).
- **النداء:** القرار على الجملة النهائية بس، بثقة كلمة «نور» + فلتر ضوضاء + أسماء منافسة في الـ grammar (يا محمد / يا ماما...) عشان «يا» لوحدها ماتفتحش.
- **ثبات الاستماع:** إصلاح سباق Threads بعد قفل/فتح الشاشة، وإيقاف المايك بتأخير 1.5 ثانية بس لما تطبيق تاني يسجل فعلاً، وبدء الاستماع فور فتح الشاشة. زرار إعدادات البطارية.
- **Markdown:** ** و * و ## و ` و ``` (بلوك كود بخلفية وزرار نسخ) وقوايم واقتباس وروابط.
- **التطبيقات:** بدون حد أقصى + بحث + تحديد الكل / إلغاء الكل. لحد 10 تطبيقات بتتكتب أسماؤها للموديل، فوق كده المطابقة جوه التطبيق (والموديل مش بيشوف القايمة).

### النسخة 5: التحكم بإيماءات اليد
- نموذجان ONNX On-Device في `assets/models/` (`palm_detector.onnx` + `hand_landmarks.onnx`) بـ ONNX Runtime، والكاميرا الأمامية بـ CameraX. مفيش فيديو بيتخزن أو بيتبعت.
- قرص الإبهام مع السبابة = ضغط (في مكان المؤشر قبل القرص بلحظة). الإبهام لوحده لفوق/لتحت = تمرير.
- إيماءاتك المخصصة: «إيماءاتي» في الإعدادات (تثبّت وضعية اليد وتربطها بفعل).
- بيشتغل والشاشة مفتوحة بس. محتاج تفعيل «التحكم بإيماءات نور» من إمكانية الوصول (للضغط والتمرير).
- الإضاءة الخافتة: رفع تعريض الكاميرا + تفتيح تلقائي. الإطار المغوّش بيتتجاهل، واليد بتتتبع من الإطار اللي قبله.

### النسخة 6
- **النداء:** نظام اكتشاف كلام (VAD) + تكبير تلقائي للصوت البعيد: Vosk مابيشتغلش في الصمت = بطارية أقل بكتير، وبيسمع «يا نور» من بعيد. إضافة نطق «ya nour» للموديل الإنجليزي، وزرار «حساسية النداء» في الإعدادات.
- **الإيماءات:** المؤشر زجاجي سائل بحركة 60fps، المؤشر بيتثبت لما الإبهام يقرّب (الضغط مابيحركوش)، تمرير بالأصابع (ينزلوا = لتحت، يطلعوا = لفوق)، علامة النصر ✌ = لقطة شاشة، وضع خمول وتوقف عند قرب الجيب/بطارية <15%.
- **أدوات الموديل:** `web_search` و`read_page` (مجاني، نتايج مصغّرة)، `read_screen`، والوقت/التاريخ جوه الـ system prompt.
- **اسأل عن الصفحة:** ضغطة طويلة على الرئيسية ← شريحة «اسأل عن هذه الصفحة» (محتاج تفعيل «استخدام النص من الشاشة» لنور في إعدادات المساعد).
- **الموديلات:** قايمة الموديلات من الـ API بتاعك في الشاشة الرئيسية (بحث + ⭐ تثبيت).
- **أدوات الصيانة:** «حالة التطبيق والإصلاح» + «تصدير سجل الأخطاء» (ملف جاهز للمشاركة).

### النسخة 7 (واجهة جديدة بالكامل)
- **الثيمين:** أسود تماماً (#000000، افتراضي) أو ألوان عصرية، من الإعدادات، وبيتطبق على التطبيق والنافذة المنبثقة.
- **انيميشن الفتح (كل مرة):** نقطة نور ← قطرة زجاج سائلة + موجة وشرارات ← اسم Nour بلمعة وبلور ← القطرة تطلع لمكانها والواجهة تدخل. لمسة = تخطّي.
- **الشاشة الرئيسية:** كرة Nour كبيرة بتتنفس + تحية حسب الوقت + شريط إدخال زجاجي (اسم الموديل، 🌐 بحث، مايك/إرسال).
- **القايمة الجانبية ☰:** كل المحادثات + بحث + ضغطة طويلة = حذف/إلغاء.
- **علامة التفكير:** كرة Nour بتلف + "Nour" بلمعة (بدل النقط).
- **بلوك الكود:** اسم اللغة + زرار نسخ + تلوين خفيف + تمرير أفقي (في التطبيق والنافذة المنبثقة).
- **مزوّدو الذكاء الاصطناعي (1 → 5):** نافذة منبثقة في الإعدادات، المفاتيح مشفّرة بـ Android Keystore، وكل موديلاتهم في قايمة واحدة مقسّمة، وآخر موديل بيتحفظ.
- **الإعدادات:** تصميم كروت زجاجية جديد.

### النسخة 8
- **اسأل عن الصفحة (بس لمواقع الويب):** أزرار زجاجية «اسأل / لخّص / ترجم»، وشريطة «الصفحة ✕» داخل الإدخال. نور بيحمّل الصفحة كاملة من رابطها (والنص الظاهر كاحتياطي).
- **البحث:** النموذج بيقرر بنفسه. أثناء البحث بتظهر كلمة «جاري البحث» / «Searching» (من غير إيموجي)، وتحت الرد زرار «المصادر · N» للرد ده بس.
- **الذاكرة:** من الإعدادات. نور بيحفظ حقائق عنك على الجهاز، وإدارة كاملة (عرض/تعديل/مسح)، ومفيش كلمات سر بتتحفظ.
